CatWar: досье агентства в игровой

Юзерскрипт для игровой страницы /cw3 на catwar.su и catwar.net: досье поверх поля, окрас искомого кота и кнопка «Начать поиски».

Скачать скрипт

  1. Установите расширение Tampermonkey.
  2. Нажмите «Скачать скрипт» — Tampermonkey предложит установку.
  3. После установки скрипт сам обновляется с этой же страницы GitHub Pages.
