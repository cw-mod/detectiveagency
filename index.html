CatWar: досье агентства в игровой

Досье поверх поля /cw3 на catwar.su и catwar.net: сворачиваемая панель, окрас искомого кота и кнопка «Начать поиски».

На Android обычный Chrome расширения не ставит, а юзерскрипты часто отключены. Для телефона — расширение в Firefox Android или в Kiwi / Lemur.

Скачать расширение (zip) Скачать юзерскрипт

Для Firefox тот же архив: detective-agency-overlay.xpi. Версия 1.3.0.

Android: Firefox

  1. Обычный Chrome на Android это расширение не установит.
  2. Скачайте zip или xpi на телефон.
  3. Временная установка (до перезапуска): на телефоне включите «Удалённая отладка по USB», на компьютере в Firefox откройте about:debugging, подключите устройство и нажмите Load Temporary Add-on — укажите manifest.json или xpi.
  4. Nightly / Beta (Android 10+): Настройки → «О Firefox» → пять раз нажмите логотип → в Настройках «Установить дополнение из файла». Неподписанный xpi Mozilla, скорее всего, отклонит; тогда используйте шаг 3.

Android: Kiwi, Lemur и другие Chromium

  1. Скачайте zip и распакуйте его.
  2. Откройте chrome://extensions, включите режим разработчика.
  3. «Загрузить распакованное» → папка с manifest.json. В Kiwi иногда можно указать сам zip.
  4. Откройте игровую /cw3 и при необходимости разрешите доступ к catwar.su / catwar.net.

Компьютер: юзерскрипт

  1. Установите Tampermonkey.
  2. Нажмите «Скачать юзерскрипт» — Tampermonkey предложит установку.
  3. После установки скрипт сам обновляется с этой же страницы GitHub Pages.

Не включайте расширение и юзерскрипт одновременно.
