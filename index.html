CatWar: досье агентства в игровой

Досье поверх поля /cw3 на catwar.su и catwar.net: сворачиваемая панель, окрас искомого кота и кнопка «Начать поиски».

Скачать юзерскрипт

Версия 1.3.1. Юзерскрипт для Tampermonkey. Автообновление: detective-agency-overlay.meta.js.

Установка

  1. Установите Tampermonkey.
  2. Нажмите «Скачать юзерскрипт» — Tampermonkey предложит установку.
  3. Откройте игровую https://catwar.su/cw3 или https://catwar.net/cw3.
  4. После установки скрипт сам обновляется с этой же страницы GitHub Pages.
